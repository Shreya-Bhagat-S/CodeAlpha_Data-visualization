# CodeAlpha - Data Visualization

## Project Overview
This project focuses on creating meaningful visualizations from the Titanic dataset using Python. It includes various charts and graphs to identify trends, patterns, and relationships within the data.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Features
- Bar Charts
- Histogram
- Pie Chart
- Scatter Plot
- Box Plot
- Correlation Heatmap
